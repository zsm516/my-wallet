# کیف پول من (اپ اندروید)

اپ شخصی مدیریت مالی (درآمد، خرج، پس‌انداز، اقساط، حساب‌ها، سرمایه‌گذاری) به‌علاوه یادداشت و لیست خرید.
قابلیت ویژه: خواندن پیامک‌های بانکی از گوشی و ثبت هرکدام که انتخاب کنی.

## راه ۱ (ساده‌تر، بدون نصب چیزی روی کامپیوتر): ساخت APK با GitHub

1. در github.com وارد حساب خودت شو و یک ریپازیتوری **خصوصی** جدید بساز (مثلاً `my-wallet`).
2. محتویات این پوشه را داخلش آپلود کن (در صفحه ریپو: Add file ← Upload files؛ پوشه‌های مخفی مثل `.github` را هم حتماً بگذار). یا با git:
   ```
   git init && git add . && git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/USERNAME/my-wallet.git
   git push -u origin main
   ```
3. تب **Actions** ← workflow به نام **Build APK** ← **Run workflow**. حدود ۵ تا ۸ دقیقه صبر کن.
4. بعد از تمام‌شدن، روی آخرین اجرا کلیک کن؛ پایین صفحه در بخش **Artifacts** فایل `my-wallet-apk` را دانلود کن (ZIP است؛ باز کن، داخلش `app-debug.apk`).
5. فایل APK را به گوشی بفرست (تلگرام، کابل، …) و باز کن. اندروید می‌پرسد «نصب از منبع ناشناس» را اجازه بده؛ بعد نصب کن.
6. اولین‌بار در اپ: یک حساب بساز ← تب تراکنش‌ها ← «ثبت از پیامک بانک» ← «خواندن از پیامک‌های گوشی» ← اجازه دسترسی به پیامک را بده.

## راه ۲: ساخت با Android Studio

1. **Android Studio** (نسخه جدید) و **Node.js 20+** را نصب کن.
2. در ترمینال داخل همین پوشه:
   ```
   npm install
   npx cap sync android
   npx cap open android
   ```
3. صبر کن Gradle همگام شود (بار اول چند دقیقه و نیاز به اینترنت).
4. ساخت APK: منوی **Build ← Build Bundle(s)/APK(s) ← Build APK(s)**. فایل در `android/app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.
5. یا مستقیم روی گوشی: USB debugging را روشن کن، گوشی را وصل کن و دکمه ▶ Run را بزن.

## نکته‌های مهم

- **دسترسی پیامک**: اندروید ۱۳ به بعد روی بعضی گوشی‌ها برای اپ‌های نصب‌شده از فایل APK دسترسی «محدودشده» می‌دهد. اگر دکمه اجازه ظاهر نشد: تنظیمات ← برنامه‌ها ← کیف پول من ← سه‌نقطه بالا ← **Allow restricted settings**، سپس ← Permissions ← SMS ← Allow.
- **ذخیره داده**: اطلاعات داخل حافظه اپ ذخیره می‌شود و با بستن اپ یا ری‌استارت گوشی از بین نمی‌رود. ولی با حذف اپ یا Clear data پاک می‌شود. قبل از آن (یا هر چند وقت) از **خانه ← 💾 پشتیبان** متن را کپی و جایی امن نگه دار.
- **آپدیت اپ**: بعد از تغییر `www/index.html`، دوباره APK بساز و روی نسخه قبلی نصب کن (اطلاعات حفظ می‌شود، چون امضای debug همان است؛ اگر از دو کامپیوتر/ریپوی مختلف بسازی، امضا فرق می‌کند و باید اول پشتیبان بگیری).
- پیامک‌های ثبت‌شده دوباره پیشنهاد نمی‌شوند.
- فقط پیامک‌های دریافتی خوانده می‌شوند و هیچ‌چیز از گوشی خارج نمی‌شود.
- پیامک‌ها اگر «تومان» نداشته باشند ریال فرض و ÷۱۰ می‌شوند. قبل از ثبت، مبلغ و نوع را چک کن.
- اپ فقط نسخه debug است که برای استفاده شخصی کافی است.

## ساختار

- `www/index.html` : کل اپ (HTML/JS)
- `android/app/src/main/java/com/zsm/wallet/SmsReaderPlugin.java` : افزونه خواندن پیامک
- `.github/workflows/build-apk.yml` : ساخت خودکار APK
